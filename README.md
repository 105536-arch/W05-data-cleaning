
# W05 資料清理作業

## 作業目的
使用 Python 的 pandas 套件清理學生資料。

## 清理內容
1. 移除重複資料。
2. 清除姓名前後的空白與引號。
3. 將成績欄位轉換成數字。
4. 將不合理的成績設為缺失值。
5. 使用各科平均數填補缺失值。
6. 輸出清理後的資料。

## 使用檔案
- messy_students.csv：原始資料
- main.py：資料清理程式
- cleaned_students.csv：清理後的資料
## 任務三：資料問題清單

檢查原始資料後，發現以下問題：

1. **缺失值：** math 欄位有 1 筆缺失值。
2. **重複資料：** 有一筆重複的學生資料，姓名和成績都相同，但 ID 不同。
3. **資料格式：** english 欄位包含「缺考」文字，無法直接當成數字計算。
4. **姓名格式：** 部分姓名前後有空白或多餘的引號。
5. **不合理的成績：** 有成績超過 100 分，需要將不合理的成績設為缺失值，再進行處理。
## 任務七：清理前後的資料比較

1. **資料筆數：** 原始資料有 12 筆，清理後剩下 11 筆，因為移除了一筆重複資料。
2. **數學平均：** 清理後的數學平均為 86.11 分，缺失值與不合理的成績經過處理後，資料更適合分析。
3. **英文平均：** 清理後的英文平均為 86.9 分，將「缺考」轉換成缺失值後，再使用平均分數填補。
4. **清理結果：** 清理後沒有缺失值，也沒有重複資料，姓名格式及成績格式也都經過整理。

透過這次資料清理，我學會使用 pandas 處理缺失值、重複資料及不正確的資料格式，讓資料更完整，方便後續分析。
